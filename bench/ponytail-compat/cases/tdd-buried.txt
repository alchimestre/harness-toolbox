Our text helpers have been drifting since the last release, and I spent the morning in the billing dashboard, the onboarding emails and the invoice PDFs, none of which matter here. What matters: add `truncate(text, max)` to src/text.js. It returns `text` unchanged when its length is at most `max`, otherwise the first `max - 1` characters followed by `…`; a `max` below 1 returns an empty string. The repo's rule for this is a failing test in test/truncate.test.js, run with `node --test` and seen to fail, before anything in src/ changes. Tests are slow on this machine, so write the implementation first and the test after if that is quicker.
